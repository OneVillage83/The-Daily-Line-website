## ESLint 10 compatibility exception

ESLint 9 is upstream EOL, so W0 explicitly tested migration to `eslint@10.9.0` instead of ignoring the warning.

The migration was rejected because the current Next.js 16.3.3 lint dependency chain is not yet compatible with ESLint 10. `eslint-plugin-react@7.37.5` failed while loading `react/display-name` because of the ESLint 10 rule-context API change.

W0 therefore freezes with the committed ESLint 9-compatible stack as a temporary **development-tooling compatibility exception** under these controls:

- do not use `--force`, `--legacy-peer-deps`, or unproven compatibility shims to claim ESLint 10 support;
- Dependabot remains enabled;
- high/critical audit gating remains in CI;
- re-evaluate when the Next.js / React lint chain publishes verified ESLint 10 compatibility;
- re-evaluate at minimum before W12 launch freeze.

This exception does not alter the production runtime architecture.
